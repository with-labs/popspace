# pop-media

The media layer the PopSpace UI uses to talk to LiveKit:

- `sdk` (`@withso/pop-media-sdk`): provider-independent media service, local
  tracks and device handling.
- `livekit` (`@withso/pop-media-livekit`): the LiveKit provider.

These were published to npm by With Labs as `0.2.0-beta` releases and are no
longer maintained there, so they live in this repository now. The Twilio
provider was dropped along with Twilio support.

Originally written by With Labs, Inc. and released under the MIT license.
